📋 Начать пересчёт

Перейдите к экрану пересчёта, загрузите PDF и начните сравнение план / факт.

❓ Как пользоваться

  1. 1С → Отчёты → Акт Ревизии → Печать → Microsoft Print to PDF
  2. Скиньте файл на телефон
  3. Здесь: Меню → Загрузить PDF → выбрать файл → ОК
  4. Вбивайте факт. сошлось, недостача, излишек
  5. Меню → Итог → Меню → Скачать PDF (имя → группа → кто считал) → печать
